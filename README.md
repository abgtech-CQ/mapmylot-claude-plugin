# Map My Lot plugin for Claude

Connects Claude to Map My Lot (`https://mapmylot.com/mcp`) and adds the lot due diligence skill: find a land lot in Australia, New Zealand, Canada or the UK, and read its outline, size and the planning and hazard layers that touch it, from official government data.

- Setup and plans: https://mapmylot.com/ai-connector.html
- Privacy: https://mapmylot.com/privacy.html
